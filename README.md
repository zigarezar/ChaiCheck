# ChaiCheck

A small iOS tea timer. The Clock app lets Auto-Lock win. This one does not.

One screen at a time. No accounts, no network, no packages.

## The point

Leave the phone on the counter. While a steep is open, Auto-Lock is off. When the time hits zero it *rings* on that still-awake screen. The 30-second second pour is why this exists.

## Sencha (the daily driver)

Three steeps, sencha-style ladder:

| | time | water |
|---|---|---|
| First | 1:00 | 70°C |
| Second | 0:30 | 80°C |
| Third | 2:00 | 90°C |

Custom teas use the same ladder from a base time.

## First launch

Empty screen, one add knob. Sencha is the featured preset; the other cards and a custom base-time live in the same sheet.

## Prototype

Run in the iOS Simulator from Xcode. Device install is a later problem — this Mac is on Xcode 15.4 / iOS 17 SDK, the phone is on iOS 26.
